# Privacy Policy

Scroll Progress does not collect, sell, or share personal information with the developer.

Scroll Progress shows a small scroll progress indicator on web pages. It reads the current page scroll position in the page context only to calculate the displayed percentage.

The extension icon can hide or show the indicator for the current tab. This toggle state is not stored and is reset when the page is reloaded.

Scroll Progress does not use analytics, advertising, tracking, remote code, Chrome storage, or a developer-operated server.
